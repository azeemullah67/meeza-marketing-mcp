About these numbers
  • Amounts stay in each account's own currency and are never converted. Totals are shown for one currency at a time.
  • Installs are attributed by each ad platform's own model. Meta and Google Ads can both claim the same install, so their installs are shown side by side and never added together.
  • "—" means the metric is not available (for example, no install tracking), not zero.
  • Data is cached for 3 minutes; Refresh fetches fresh data. Today's numbers are incomplete on every platform.
